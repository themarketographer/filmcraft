# Estudio Marketographer app icon

**Design:** the white camera mark of The Marketographer brand (white on black), taken from the brand
folder. The SVG (`filmcraft.svg`) embeds the square image inside the usual rounded tile (`rx=112`).

**Not open source:** this icon is a brand asset. See [LICENSE.txt](LICENSE.txt). It is not covered by
the code's MIT OR Apache-2.0 licence.

## Files

- `filmcraft.svg`: the master, a 512-unit tile with the brand image.
- `filmcraft-small.svg`: a copy for the Linux icon theme.
- `packaging/icons.sh` regenerates every PNG, `.icns` and `.ico` from `filmcraft.svg` (needs `resvg`).
