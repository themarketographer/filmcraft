# Estudio Marketographer app icon

**Design:** a dark film frame with a play triangle on the brand yellow tile (`#fddc5b`).
Drawn in code as SVG (`filmcraft.svg`), original work for this fork.

## Files

- `filmcraft.svg`: the master artwork, a 512-unit tile with rounded corners (`rx=112`).
- `filmcraft-small.svg`: a copy for the Linux icon theme.
- `packaging/icons.sh` regenerates every PNG, `.icns` and `.ico` from `filmcraft.svg` (needs `resvg`).
