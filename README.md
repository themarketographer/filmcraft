# Estudio Marketographer

Editor de video para crear contenido: títulos animados, subtítulos con palabra activa, look de película, zooms, recorte de la persona, Talking Head y Pro vs Noob.

Es una versión modificada de **FilmCraft**, de ArtCraft team, un editor de video no lineal escrito en Rust. Esta versión la hace The Marketographer y no está hecha, avalada ni soportada por ArtCraft team.

## Compilar

Necesitas Rust 1.95 o más nuevo.

```bash
cargo run --release -p filmcraft
```
